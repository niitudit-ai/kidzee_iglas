# Launch Checklist — website live karne se pehle

Isko order se karo. Har item tick karte jao.

---

## 🔴 Phase 1 — Ye kiye bina website live MAT karo

- [ ] **Zee Learn se written approval** mil gayi (dekho `01-zee-learn-approval-email.md`)
- [ ] **Official Kidzee logo** mil gaya → `assets/img/logo.png` par save kiya
- [ ] **Official brand colours** mil gaye → `style.css` ke `:root` mein update kiye
- [ ] Poori website ka **text padha** aur jo aapke centre par lagoo nahi hota wo hataya:
  - [ ] "Why Us" ke 6 cards — sirf jo sach hai wahi rakha
  - [ ] Programs ke **age bands** confirm kiye (1.5–2.5 / 2.5–3.5 / 3.5–5.5)
  - [ ] **Daily routine ki timings** apne actual schedule se match ki
  - [ ] **Documents list** confirm ki
  - [ ] FAQ ke jawab check kiye (timings, fees, age)
- [ ] **Testimonials** — 3 asli parents se permission le kar unke asli shabd daale
      *(placeholder `[Parent's Name]` ke saath live mat karo)*
- [ ] **Photos** daali — kam se kam hero + 3 gallery photos
      (dekho `assets/img/README.md`)
- [ ] Jin bachchon ke photo use kiye, unke **parents se likhit permission** li
- [ ] **Founding year** check kiya — `index.html` ke schema mein `"foundingDate": "2016"`
      likha hai. Agar actual year different hai to badal do

---

## 🟡 Phase 2 — Domain aur hosting

- [ ] Domain khareeda: **kidzeeiglas.com** (ya `.in`)
      *(GoDaddy / Hostinger / BigRock — approx ₹700–1200/saal)*
- [ ] Website upload ki (dekho `README.md` — free Netlify se ho jaayega)
- [ ] **HTTPS** chal raha hai (address bar mein 🔒 dikhe)
- [ ] Agar domain different rakha, to in files mein domain badal do:
  - [ ] `index.html` — canonical, og:url, og:image, aur schema ke URLs
  - [ ] `sitemap.xml`
  - [ ] `robots.txt`
- [ ] `share-preview.jpg` bana kar daali (1200 × 630 px) — WhatsApp par link bhejne
      par photo dikhegi

---

## 🟢 Phase 3 — Test karo (10 minute, bahut zaroori)

Ye sab **apne phone par** karo, laptop par nahi:

- [ ] Website mobile par khuli aur theek dikhi
- [ ] **"Call Now" button** dabaya → phone dialer khula with 91933 33793
- [ ] **WhatsApp button** dabaya → WhatsApp khula, message pehle se likha aaya
- [ ] **Enquiry form** bhara aur submit kiya → WhatsApp par poori detail aayi ✅
      *(ye sabse important test hai — isse aapke leads aayenge)*
- [ ] **Hindi toggle** (हिं) dabaya → poori website Hindi mein badli
- [ ] **Hamburger menu** khula aur band hua
- [ ] **FAQ** ke sawaal khule aur band hue
- [ ] **Map** load hua aur sahi jagah dikhaya
- [ ] Kisi aur ke phone par bhi khol kar dikhaya (Android + iPhone dono agar ho)
- [ ] Slow internet par bhi khul rahi hai (mobile data 4G off karke test karo)

---

## 🔵 Phase 4 — Google par register karo

- [ ] **Google Business Profile** banaya/claim kiya (dekho `03-google-business-profile.md`)
- [ ] GBP verify hua
- [ ] GBP par 15+ photos daali
- [ ] GBP par website ka link daala
- [ ] Website ke schema mein **latitude/longitude** daala
- [ ] **Google Search Console** ([search.google.com/search-console](https://search.google.com/search-console))
      par site add ki → `sitemap.xml` submit kiya
- [ ] Google par khud search kiya: "kidzee iglas" — website dikhi
      *(2-4 hafte lag sakte hain — dhairya rakho)*

---

## 🟣 Phase 5 — Social media

- [ ] **WhatsApp Business** app setup (greeting, away message, quick replies, catalog)
- [ ] **Facebook Page** banaya, bio bhara, WhatsApp button lagaya
- [ ] **Instagram** `@kidzee_iglas` banaya, business account mein convert kiya
- [ ] Dono par **website ka link** daala
- [ ] `index.html` ke footer mein social links ke `href="#"` ko asli URLs se badla
- [ ] `index.html` ke schema mein `"sameAs": []` bhara
- [ ] Pehla post daala (Day 1 ka caption ready hai)
- [ ] **Canva** par Brand Kit banaya (colours + fonts + logo)

---

## ⚪ Phase 6 — Offline

- [ ] Pamphlet design karwaya aur print kiya (content `04-social-media-30-day-plan.md` mein hai)
- [ ] Gate ka board check kiya — Kidzee logo saaf dikh raha hai?
- [ ] Gonda Road par direction board lagaya
- [ ] Visiting card banwaya (naam, phone, address, website, QR code)
- [ ] Google review ka **QR code** print karke reception par lagaya
- [ ] Purane parents ko WhatsApp par website ka link bheja
- [ ] Referral scheme announce ki

---

## 🔁 Har hafte (15-30 minute)

- [ ] 3 social media posts (Mon / Wed / Fri ya Sat / Sun)
- [ ] Roz 1 story
- [ ] GBP par 1 photo + 1 post
- [ ] Naye Google reviews ka jawab
- [ ] WhatsApp enquiries ka same-day reply

## 🔁 Har mahine

- [ ] 2-3 naye Google review maange
- [ ] Website ki gallery mein naye photos daale
- [ ] Metrics note kiye (calls, enquiries, visits, admissions)
- [ ] Har naye parent se poochha: "aapne kahan se suna?"
