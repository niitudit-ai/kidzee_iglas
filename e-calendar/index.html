📢 Sabko dikhaayein

Aapke badlaav abhi sirf aapke browser mein hain. Neeche ke 3 step karne se calendar GitHub par save ho jaayegi aur phir jo bhi link kholega, usko wahi dikhega.

⚠️ Dhyan dein: is beech kisi aur ne nayi calendar publish ki hai. Aap publish karenge to unke badlaav hat sakte hain. Pehle 🔄 Refresh dekh lena behtar hai.
  1. JSON copy karein
  2. GitHub par file kholein aur paste karein

    Link khulega → andar ka purana text Ctrl+A se select karein → Ctrl+V se paste karein → neeche “Commit changes” ka hara button dabaayein.

    Link khulega → text par der tak ungli dabaayein (long press) → “Select all” chuniye → phir “Paste” dabaayein → neeche tak scroll karke hara “Commit changes” button dabaayein.
    Phone par ye thoda mushkil hai. Ho sake to laptop se publish karein, ya neeche wala “file upload” tareeka use karein.

    🔗 GitHub par kholein
    Paste karna mushkil lag raha hai? File upload kar dein

    File download karke GitHub ke upload page par drag-drop kar dein — wo purani file ko apne aap badal degi. Naam calendar.json hi rehne dein.

    🔗 Upload page kholein
  3. Wapas aakar check karein

    Commit ke baad GitHub ko 1–2 minute lagte hain. Phir ye button dabaayein — hum khud dekh lenge ki sabko naya calendar pahunch gaya ya nahi.

Jo JSON paste karna hai wo dekhna hai?

⌨️ Keyboard shortcuts

← / → — previous / next month (year view mein previous / next year)

T — aaj ki date par jaayein

M / A / Y — Month / Agenda / Year view

N — naya event (sirf admin)

/ — search box par focus

D — dark / light mode

P — print / save as PDF

Esc — koi bhi popup band karein

📢 Ye badlaav sirf aapko dikh rahe hain
